# Аудит 116 профилей Board: VALORANT 13.08

Проверяется установленная сборка `13.08.00.5715960`, manifest `7A64CDDDEC7CDB4C`. Этот документ — аудит выбранных источников и игровой семантики, **не подтверждение готовности всех способностей** и не verification receipt. Чтение чисел из CDO недостаточно: tuning, runtime setters, наследование, стадия эффекта и область применения должны быть прослежены отдельно.

1. Jett native module clock/длительность применения и реальный интеграл движения; серверные настройки/проверка в актуальной игре.
2. Специфические ограничения всех управляемых/AI/movement routes. Наличие свободного path и отсутствие maxLength нельзя трактовать как бесконечность. Phoenix Curveball, Yoru decoy и Vyse/Cypher стены нельзя считать произвольными маршрутами из-за общего типа path.
3. Не хватает составности: до 3 Seekers, варианты dash Waylay/Neon, фиксированный return anchor и путь Phoenix/Waylay, финальная зона Tejo Drone, центр slow Chamber, все нужные linked targets/стадии.
4. Ground patches и terrain-dependent walls нуждаются в фактической геометрии карты. Viper Pit не завершён: см. [native/terrain research](board-data-terrain.md). Круг ClampedRadius — максимум, не проверенная полная область реальной поверхности.
5. Полный набор cast/owner/activation/detection/range/width/stage данных следует хранить раздельно; множество слотов пока включает только footprint эффекта. Это нельзя исправить копированием ближайшего числа из того же пакета.
6. Не установлены итоговые live server/config overrides каждого параметра. Offline соответствие ресурсу и успешное размещение 116 иконок не заменяют игровое подтверждение спорных параметров и удобства всех режимов.

Перечень не разрешает скрывать незавершённые способности или выдавать старый snapshot за проверенный. Полная публикация набора должна оставаться заблокированной, пока соответствующие unresolved пункты не закрыты доказательствами.
