# Agent Academy 0.7.4 — 2026-10-26

This Windows update fixes public-feed video viewing and the lineup detail header.

- Original Tracker clips play directly in the detail view, automatically and initially muted. Existing managed entries have verified Stream player URLs; older personal copies can resolve their original player's metadata.
- The map thumbnail uses the same splash artwork as the home map cards, beside the agent portrait.
- Video appears above the instructions. External pages without a supported embedded player have an original-guide link and an `External guide` cover label.
- Supported video players can enter fullscreen in Electron; native Escape returns to the detail view.
- The current library includes 278 records on the seven reviewed Competitive maps, including 23 Tracker entries and four new Fade/Abyss demonstrations. The 500-record content goal remains incomplete.

The existing preview configuration and backend are retained. The installer is unsigned, as in 0.7.3, and distributed through the existing GitHub update feed at [Agent-Academy](https://github.com/whit33th/Agent-Academy/releases/tag/v0.7.4). The source repository is [valorant-picker](https://github.com/whit33th/valorant-picker).

Validation before publication:

- 294 tests, lint, type checks and the bundled Next.js/Electron build passed.
- All 23 Tracker records played and advanced muted in Chrome and development Electron; YouTube chapter playback, narrow windows, offline/reconnect and player controls were also checked.
- A packaged 0.7.4 test payload loaded the real dev feed, displayed the home map artwork, decoded/played a Tracker clip muted, entered fullscreen and returned with native Escape. A separate profile and test port preserved the running installed client. Evidence: `outputs/desktop-video-release-qa/report.json`.
- The full NSIS installer, blockmap and `latest.yml` come from the same build; the declared size and SHA-512 were verified. GitHub discovery/download is checked after publication with `node scripts/desktop-update-qa.mjs --live --from=0.7.3 --expected=0.7.4`.

Installation is an explicit action in Settings: `Check for updates` → `Download update` → `Restart and update`. Publishing or downloading does not itself install the update on the user's machine.
